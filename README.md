# Projeto da materia de Autoria Web
### Produção de uma pagina copia do Wikipedia.
**Descrição:**
Este projeto foi desenvolvido como parte do estudo de **HTML** e **CSS**, com o objetivo de replicar a página da Wikipedia. A recriação envolveu a reprodução da estrutura de conteúdo, navegação e estilo visual, permitindo uma compreensão mais profunda de como páginas da web organizam e apresentam grandes volumes de informações de maneira eficiente.
